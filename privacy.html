隱私權政策 Privacy Policy

最後更新：2026-11-11 · Last updated: 2026-11-11

適用範圍

robo-Hermes 只供本人使用，在本人自己的電腦上執行，沒有其他使用者。

存取哪些資料

經本人授權後，robo-Hermes 透過 Google Calendar API 讀取本人的日曆清單與行程，並依本人的指示新增、修改或刪除本人日曆上的行程。它不存取 Gmail、雲端硬碟或其他 Google 服務的資料。

資料如何使用與保存

  • 行程資料只在本人的電腦上處理，用來回答本人的問題與管理本人的行程。
  • 授權權杖只存在本人電腦的本機檔案中。
  • 不出售、不分享、不傳給任何第三方，也不用於廣告或訓練模型。

撤銷授權

可以隨時在 Google 帳戶的「第三方應用程式和服務」頁面（myaccount.google.com/connections）移除 robo-Hermes 的存取權。

English summary. robo-Hermes is used only by its owner on the owner's own computer. With the owner's authorization it uses the Google Calendar API to read the owner's calendars and events and to create, update or delete events at the owner's request. It does not access Gmail, Drive or other Google data. Calendar data is processed only on the owner's computer; the authorization token is stored only in a local file there. No data is sold, shared or sent to any third party, or used for advertising or model training. Access can be revoked at any time at myaccount.google.com/connections.
